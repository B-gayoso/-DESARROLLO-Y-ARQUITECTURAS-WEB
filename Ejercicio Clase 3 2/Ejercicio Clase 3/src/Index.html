Elementos Semánticos en HTML5

HTML5 introdujo nuevos elementos semánticos que permiten estructurar mejor las páginas web y hacer el contenido más accesible tanto para los usuarios como para los motores de búsqueda. Estos elementos describen claramente su propósito dentro del documento.

1. <header>

Representa el encabezado de una sección o de todo el documento. Puede incluir logotipos, títulos o menús de navegación.

2. <nav>

Se utiliza para contener enlaces de navegación que permiten moverse por las diferentes secciones de un sitio.

3. <section>

Define secciones genéricas del contenido, que normalmente tienen su propio encabezado.

4. <footer>

Representa el pie de página de una sección o del documento completo, e incluye datos de contacto, enlaces o derechos de autor.
